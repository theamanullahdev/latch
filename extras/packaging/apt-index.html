Latch

apt repository for Linux Mint 22 and Ubuntu 24.04 (amd64)

Latch switches Wine, xdotool and the firewall on and off from one window. It is an early prototype. Source and docs: github.com/theamanullahdev/latch.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://theamanullahdev.github.io/latch/key.asc | sudo gpg --dearmor -o /etc/apt/keyrings/latch.gpg
echo "deb [signed-by=/etc/apt/keyrings/latch.gpg] https://theamanullahdev.github.io/latch stable main" | sudo tee /etc/apt/sources.list.d/latch.list
sudo apt update
sudo apt install latch

Remove

sudo apt remove latch
sudo rm /etc/apt/sources.list.d/latch.list /etc/apt/keyrings/latch.gpg

If Wine or xdotool is locked when you remove Latch, unlock it first. See the Security section.
